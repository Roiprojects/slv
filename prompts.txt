# MASTER WEBSITE DEVELOPMENT PROMPT — SLV BOREWELLS

## 1. Project Overview

Build a complete, modern, professional, visually appealing, fully responsive **static informational website for SLV Borewells**, a borewell drilling and water solutions business serving Bengaluru and surrounding areas.

Use the uploaded website screenshots and the reference website https://sanidhyaborewells.in/ as inspiration for layout, page structure, content organization, service presentation, and industry-specific information.

**Important:** Do not replicate the reference websites exactly. Create a distinctive, premium, trustworthy, and friendly identity for SLV Borewells.

The website should combine:

- The premium, spacious, modern design of the first reference.
- The drilling machinery imagery and industrial credibility of the other references.
- The structured service catalog, gallery, and detailed service information.
- A beautiful, minimal, slightly cute visual style using soft shapes and subtle water-inspired decorations.
- Excellent readability, intuitive navigation, smooth interactions, and mobile responsiveness.

The website is primarily informational, not an e-commerce or booking platform.

## 2. Technology Stack

Use:

- **Astro** — static website framework.
- **Tailwind CSS** — responsive styling and design system.
- **TypeScript** — structured content and configuration.
- **Vanilla JavaScript** — lightweight interactions.
- **Lucide Icons** — consistent icons.
- **Google Fonts** — Plus Jakarta Sans and DM Sans.
- **Astro Image optimization** — optimized responsive images.

Use static site generation.

Do not implement a backend, database, login, authentication, payment system, or admin dashboard.

The final project should be deployable to Cloudflare Pages, Netlify, or Vercel as a static site.

## 3. Brand Identity and Color Palette

Business Name: **SLV Borewells**

Industry: Borewell Drilling, Groundwater Solutions, Pump Installation, and Related Services.

Brand Personality:

- Professional
- Trustworthy
- Technically capable
- Modern
- Approachable
- Slightly playful
- Customer-focused

### Color System

Primary Dark Teal: `#123D4A`

Primary Aqua Blue: `#36B6C5`

Warm Cream Background: `#FFF9EF`

Soft Mint Background: `#DDF5EC`

Soft Coral Accent: `#FF977D`

White Surface: `#FFFFFF`

Dark Text: `#17323B`

Muted Text: `#61747A`

Use deep teal for headings, the footer, important backgrounds, and primary buttons. Aqua blue should appear in icons, links, decorative elements, and active states. Warm cream should be the dominant page background.

Use coral sparingly for small visual accents.

Ensure adequate accessible contrast for all text and buttons.

### Typography

Headings: Plus Jakarta Sans, bold or semibold.

Body: DM Sans, regular and medium.

Use large expressive headlines, occasional italic accent words, readable paragraphs, and generous whitespace.

Avoid excessive uppercase text, tiny fonts, or long dense paragraphs.

### UI Styling

- Rounded cards with approximately 16–24px border radius.
- Subtle shadows and lightweight borders.
- Pill-shaped buttons.
- Soft aqua highlights.
- Minimal line icons.
- Alternating warm cream, white, mint, and deep teal sections.
- Curved or organic water-inspired accents.
- Consistent card spacing and image aspect ratios.
- Maximum main content width around 1200px.
- Subtle hover transitions and scroll reveal animations.
- Respect reduced-motion accessibility settings.

Avoid excessive gradients, harsh colors, oversized floating elements, and unnecessary animations.

**The visual target is 75% premium professional and 25% friendly/playful.**

## 15. Responsive Design

Build mobile-first.

Suggested breakpoints:

- Mobile: below 768px.
- Tablet: 768px–1023px.
- Desktop: 1024px and above.

Requirements:

- No horizontal overflow.
- Readable text at all sizes.
- Responsive hero imagery.
- Stacked layouts on smaller screens.
- Touch-friendly buttons.
- Mobile hamburger navigation.
- Responsive service and gallery grids.
- Easy-to-access call and WhatsApp actions.
- Consistent margins, padding, and section spacing.

## 16. SEO and Accessibility

Implement:

- Semantic HTML.
- Unique titles and meta descriptions.
- Proper heading hierarchy.
- Open Graph metadata.
- Canonical URLs.
- XML sitemap.
- Robots.txt.
- LocalBusiness structured data using verified company information.
- Service-related page metadata.
- Descriptive image alt text.
- Accessible keyboard navigation.
- Visible focus indicators.
- Accessible form labels.
- Sufficient color contrast.
- Fast-loading optimized assets.

Target good Core Web Vitals and strong Lighthouse scores.

## Final Design Objective

Create an original, memorable, modern borewell company website that communicates **trust, technical expertise, reliability, and approachable customer service**.

The website should feel like a premium local engineering and water solutions brand, rather than a generic construction template.

Use expressive typography, beautiful real-world drilling photography, restrained aqua-blue accents, cream backgrounds, subtle animations, and carefully organized information.

Prioritize **excellent frontend quality, responsive behavior, clear service information, speed, and easy customer contact**.

The final result should be visually more refined than the reference websites while retaining their useful business-specific structure and content depth.
